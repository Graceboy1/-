# 全球新闻

本机独立预览，不替换正式入口、不重启正式服务、不读取账户或模型配置。

采用版现已作为正式工作台的第四项“新闻页”集成，入口为
`http://127.0.0.1:3001/?desk=news`（正常登录后进入）。正式站使用构建时生成的
`web/public/news-earth` 同源资源，不依赖这个 3008 预览进程；新闻页切走后卸载画布。
修改本目录后需在 `web` 执行 `npm run build` 或 `node tools/prepare-news.cjs` 同步资源。

## 设计系统

沿用现有预览的石墨底 `#121418`、冷蓝 `#afc1db` 和思源/Noto CJK 字体栈。
正文 14–16px，标题 19–30px；半像素细边框和低强度微光。国家只做中性选中高亮；
红 `#f4787f`、绿 `#67c89d` 仅用于板块影响示例，明暗为人工等级，非概率。

已采用第二版轨道观测台，默认地址 `http://127.0.0.1:3008/`，旧会话或普通 view 参数不会改变采用版本。
其余设计稿保留在显式对比模式（compare=1），不显示于默认页面：

- `http://127.0.0.1:3008/?compare=1&view=atlas` 地图资讯台：大幅裁切地图与侧边新闻卡。
- `http://127.0.0.1:3008/?view=orbit` 轨道观测台：较完整球体、环轨和紧凑新闻流。
- `http://127.0.0.1:3008/?compare=1&view=horizon` 地平线视窗：球心下移、30°倾斜视线、弧形地平线。

## 行为

左侧保留全部 15 条演示新闻，只有用户输入搜索词才过滤。
地点支持国家、省/州、城市；列表、详情和地图标注使用同一份地点字段。
国内增加广东省深圳市、浙江省杭州市的城市定位示例，直辖市名称不重复。
省市搜索支持组合输入；缺失行政层级不猜测，缺少坐标不定位。
点击新闻立即更新内容并开始约 430ms 的最短经度转向；后一次选择取消前一次动画。
减少动态效果模式直接定位。同一坐标的多条新闻聚合；点击地图点同步列表，并展开该处全部新闻。
无坐标新闻不放置假位置，保留当前视角。

拖动可双轴旋转，滚轮横转、Shift+滚轮纵转；方向键或按钮也能操作，Home 回到选中新闻。
点击“进入关联板块”后显示该新闻全部明确关联板块，再进入当前席位的模拟标的；
各席位规则独立，零结果不填入无关股票。Escape 返回上层。
股票层上方为“返回板块”，板块层为“返回新闻页”；面包屑“新闻页”可直接回到地球新闻界面。

常规界面的重复“演示/模拟标的”注释已收拢到顶部常驻的“数据状态：模拟”；悬停可查看
未接入实时新闻和行情的说明。底层数据 provenance、原始解释、规则与行情状态均未改变。

辅助小字继续精简：去掉球内层级、节点数量、旋转/点击操作提示、重复席位说明及无代码占位。
关联区不再绘制圆球及连线，股票表保留方向、等级、筛选状态和详情操作；定位按钮与键盘/拖动交互不变。
定位状态和过滤数量说明保留为无障碍文本，不占画面空间。

关联区原说明文案已替换为股票列表：新闻层汇总所有关联板块；板块层只显示该板块。
股票按唯一 ID 去重，保留全部相关板块；每行显示模拟名称、关联板块、影响方向/演示等级、
当前席位门槛结果，点击“查看原因”展开关联解释和规则。未提供证券代码时明确标为模拟标的，
不把内部 ID 冒充股票代码。取消“仅看门槛通过”可看未通过或缺失结果，不混用席位。

## 性能与边界

地图和三个绘图库已锁版保存在本地，无运行时 CDN 请求、无自动新闻轮询、无模型调用。
按交互/尺寸变化绘制，DPR 上限 1.5，静止时无动画循环。
新闻归属地点为演示城市锚点，不是已核实的事件位置；底图为地理示意，非标准地图。
本次细化的是新闻归属与城市定位，底图仍是国家级边界，未新增省市行政边界图层。
详见 `DATA-SOURCES.md` 的地图来源、许可证和 SHA256。
