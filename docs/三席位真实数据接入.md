# 三席位真实数据与正式演示

本说明描述折叠区的单股证据研究；主界面现另有[自主模拟账户](自主模拟交易.md)，采用明确估算假设产生组合模拟订单，不能与这里的严格成交证据校验混为一谈。

正式研究、复盘、审计共用本机已下载的沪深主板非ST股票目录，排除创业板、科创板和北交所。选择股票后切换基础、利弗莫尔、巴菲特，保持同一真实代码和名称；预案、规则、引用证据和归档仍按席位分别保存。缺档案时展示数据导入提示，不用虚构股票补齐。

## 可用证据与不能替代的内容

| 席位 | 使用真实数据 | 仍需核对 |
| --- | --- | --- |
| 基础 | 截至2026-11-12的真实日线与均线、量比、价格区间 | 历史精确涨跌停、完整停复牌及执行证据 |
| 利弗莫尔 | 同股真实日线，计算120日最高、最低及区间位置 | 决策日精确封涨停状态、次日竞价成交额、指数竞价与区域条件 |
| 巴菲特 | 同股真实价格，读取本地年度财务参考 | 原始历史报表版本、维持性开支、准确股数、人工能力圈及护城河说明 |

任何席位都不将当前名称名单推定为历史ST状态，不把涨约10%当成精确涨停，不用全天成交量替代竞价，不用日线猜财报。缺失值保留未知，不强行让规则通过。

## 真实财务参考

财务下载器读取东方财富公开财务表及业绩报表，按证券代码、年度报告期和披露日期核对2023、2024、2025年度资料。只供个人本机研究，来源为当前检索到的历史报表记录，**未确认这些是决策日当时可见、未经后续重述的原始版本**。因此`point_in_time_verified=false`，仅出现在`raw_reports`财务参考中，不进入严格历史决策的`financial_reports`。

- [东方财富公司财务分析入口（贵州茅台示例）](https://emweb.eastmoney.com/PC_HSF10/NewFinanceAnalysis/Index?code=SH600519&type=web)
- [东方财富公司业绩报表（贵州茅台示例）](https://data.eastmoney.com/bbsj/yjbb/600519.html)

展示经营现金流、购建固定资产等长期资产的现金支出、净利润、ROE和负债权益口径；按原始数据保留字段来源、报告期、公告日期及抓取时间。金额归一为百万元。购建长期资产现金支出不是维持性资本开支，不能擅自改名替代；股本金额也不能擅自当股数。当前没有精确股数及人工生意认可时，不计算伪造的每股估值或自动通过价值规则。

正式目录中的“已有财务资料”入口只表示本机有可读参考资料，不表示推荐、财务质量通过、价格低估或可以成交。支持少量指定股票或明确执行全主板批量下载；选择和切换股票只读缓存，不暗中请求财报或付费模型。

2026-11-16本机已实际下载并通过文件校验的参考为6只、每只3个年度，共18条：000333美的集团、000858五粮液、600406国电南瑞、600519贵州茅台、600887伊利股份、600900长江电力。其他股票仍使用真实日线，但未下载财务参考时明确标记缺失；不是全市场财报已完成。

2026-11-17起新增全主板三年四表补齐工具和逐项数据清单；这不自动改变上述历史版本核验结论。最新实际下载覆盖以 `fundamentals/coverage.json` 为准，原始年报下载情况以 `fundamentals/originals/manifest.json` 为准；已取得、缺失、版本歧义和人工待确认分开记录，详见[巴菲特数据补齐说明](巴菲特数据补齐说明.md)。

## 正式演示顺序

1. 登录，选离线模式即可使用已下载行情；无需为展示股票调用模型。
2. 选择股票，核对真实名称、代码、档案截至日及决策截止日。
3. 在同一股票上切换三个席位，查看实际指标、原始财务参考及缺失条件。
4. 主动生成并冻结预案，查看审计台记录的证据和风控理由。
5. 观望预案可以揭示11月13日真实后续价格；缺执行依据的条件预案拒绝成交。无买卖时显示无订单、无持仓，不用旧合成交易补画账本。

本批只有一个决策日后的观察日，不能演示真实买入后T+1卖出，也不能拿当日涨跌当作可兑现的收益率。未来若补充合规的历史竞价、证券状态、财报版本和更长后续窗口，须独立验证后再启用交易模拟。

## 存储、内存与旧档案

日线仍按单股gzip读取，列表分页20条，送入研究证据最多120根。财务档案独立放在`data/market-history/2026-11-13/fundamentals/`，单文件及索引有容量和SHA-256校验，缺失/损坏不回退合成值，目录提示最多40只，不把全市场载入浏览器。

`GET /cases`默认只返回首批有界的真实股票摘要；合成用例仅保留显式`source=examples`开发兼容入口与测试。已有冻结记录不改写，重启后按原快照只读查看，不自动重算或覆盖。数据、账号、研究库、API Key不进入公开源码包；公开传播原始行情和新闻/财报资料前须另核对许可。本次只更新本机正式站，不自动改动已封存参赛ZIP/PDF。
