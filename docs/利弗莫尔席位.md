# 利弗莫尔席位 · v0.2 接入说明

参赛版新增「利弗莫尔席位」，按用户本地旧包中标为 v2.1 的核心规则独立实现。来源口径是该项目的席位规则，并不等同于杰西·利弗莫尔本人的完整交易方法；不宣称模型训练、授权或历史盈利。新代码不运行旧包脚本，不打包它的源码、数据库、历史账本或候选名单。

本文记录早期合成分支的规则与测试设计，不是当前默认网页演示或全市场交易结果。2026-11-17正式接入及限制见[利弗莫尔数据接入验收](利弗莫尔数据接入验收.md)；当前严格证据缺失，实时新增买入仍关闭。

## 用真实规则走通单标的合成案例

1. **盘后选候选**：只读决策日收盘及以前的数据。排除 ST 和退市标的；当天必须收盘涨停；需有至少 120 根有效日线，区间位置 `(决策收盘 - 120日最低价) / (120日最高价 - 120日最低价)` 严格小于 10%。没命中就空仓，不放宽门槛。
2. **冻结后才看次日竞价**：模拟竞价涨幅落在 `(0%, 7%]`，并校验指数竞价及区域风险标记。三项通过是 5,000 元观察仓，两项通过降为 3,500 元，其余空仓。平开、低开、超带及开盘封板拒单。委托预算超过合成竞价成交额的 5% 时拒单；不能用当天总量代替竞价额。
3. **隔日收盘退出**：买入当日不能卖。次一交易日以收盘价作虚拟记账，收盘涨停可按 Z1 顺延一次；跌停无法退出时，转为下一可成交开盘退出。停牌和样本不足时保留未平仓状态。仓位预算含费用，按 100 股整手，不套用旧包的一手豁免。

界面可演示正常成交、平开拒单、未入候选、Z1 顺延、竞价量不足、跌停延后退出和降仓。均为合成情境；不接实盘，也不是全市场候选池回测。区域风险是夹具输入，不自动猜测真实新闻；单票场景只演示 gate B 的单票口径。收盘成交、竞价及排队判断都是有说明的模拟假设。

## 不影响后续席位

`server/seats.py` 登记各席位的证据读取、预案生成、校验和回放政策。生成时冻结席位身份及策略参数，回放仅接受会话 ID，不能切换成另一席位或改仓位。旧「基础演示席位」仍可选择，继续使用原价带和三日回放政策。各次模拟拥有独立虚拟资金与持仓；没有接入旧账本或常驻组合。

v0.3 已独立接入[巴菲特席位](巴菲特席位.md)，使用带可用日期的合成财报、价值估算和安全边际，不继承利弗莫尔的隔日退出。长期真实组合、分批调仓和财报驱动卖出仍须单独实现。

## 评审演示顺序

先演示「利弗莫尔席位」的普通成交，指出时点证据和策略门槛；切换「未入候选」看明确空仓；再用「平开拒单」说明候选不等于成交，用「Z1 顺延」展示席位独立退出政策。最后切回基础席位，确认旧流程仍可用。

利弗莫尔是确定性规则策略，不调用大模型；基础席位仍可选择配置后的真实 AI 模式。不要把席位规则演示说成模型推理。原技术 PDF 讲的是 v0.1 基础席位；本说明是 v0.2 的席位补充，提交材料时需一并更新演示内容。
