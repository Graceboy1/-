# 利弗莫尔全市场数据接入

2026-11-17。本次接入的是文件包思想启发的 v2.1 规则所需数据，不是利弗莫尔本人的模型、交易建议或完整实盘系统。旧订单、持仓、研究档案不重算，不启动用户账户交易。

## 本机实际下载及离线核对

固定历史演示的决策日为 2026-11-12，观察/执行日为 2026-11-13，不冒充今日行情。沿用 3,049 只沪深主板非 ST/退股票档案，排除创业板、科创板及北交所。

| 数据 | 核对结果 |
| --- | ---: |
| 有效读取的本地股票档案 | 3,049 |
| 决策日已有至少120根日线 | 3,035 |
| 120日区间位置严格低于10% | 816 |
| 决策日同日价格匹配的来源涨停参考 | 37 |
| 精确历史涨跌停价及当时证券状态来源档案 | 0 |
| 真实股票竞价 / 指数竞价 / 区域确认 | 0 / 0 / 0 |
| 严格结构候选 / 执行证据就绪 | 0 / 0 |

涨停池通过东方财富普通公开网页所用的匿名接口读取，保留原响应、查询日期、取得时间及 SHA256，并逐股核对相同日期的本地不复权日线收盘价。接口 `qdate` 是原样保存的服务器字段，**不当作事件日**；两天分别请求、分别匹配价格。`p/1000` 单位来自该网页公开价格格式化方式。没有账户密钥或 Cookie。

这些记录只叫“来源涨停参考”，不提供精确涨停价，不证明历史 ST/停牌状态；未列入池也不代表已核验未涨停。不得用涨约10%、当日最高价或全天成交量补造缺项。

## 数据链和页面

- `server/livermore_reference.py`：按日期及内容指纹读取参考，仅保留两个日期的有界缓存。
- `server/livermore_data.py`：读取独立本地严格证据，分离决策日限价/状态和次日9:25股票竞价、指数竞价、事前人工区域确认。
- `historical_seats.py` / `paper_market.py`：三个席位共用全市场档案；只用截止前日线及决策日证据产生利弗莫尔条件预案，次日数据不回填信号。规则代码与决策证据有独立指纹。
- `paper_engine.py`：实际模拟买入前再次独立核验竞价；按原规则限额 3,500 或 5,000 元，预算还受账户仓位、现金、100股及费用约束。缺证据不创建订单。
- 研究台、审计台主区增加接入状态卡，复盘台不重复。接口读取离线覆盖回执，不在每次页面刷新时扫描全市场，不自动下载/调用 AI。

完整真实竞价和历史证券状态需要合法授权来源或已经核实的本地原始资料，本次没有伪造。`source_verified` 字段与格式检查不能代替实际来源核实、数据授权或真实成交证明。

## 采集与后续导入

在项目根目录执行（`--dry-run` 不联网、不写入）：

```powershell
.\.venv\Scripts\python.exe tools/download_livermore_data.py --dry-run
.\.venv\Scripts\python.exe tools/download_livermore_data.py
.\.venv\Scripts\python.exe tools/download_livermore_data.py --refresh-coverage
```

正式采集核对公开页面后，每个固定日期只请求一次涨停池。401、403、429 或跳转立即停止，不更换地址绕过。参考文件不可变、索引最后提交；失败不把旧资料改成空池。`--refresh-coverage` 只读取本地档案。

以后取得真实授权证据后，可显式本机导入（不提供远程上传入口）：

```powershell
.\.venv\Scripts\python.exe tools/import_livermore_evidence.py --input "本机授权证据.json" --code 600000 --dry-run
```

先自行核实文件来源与授权、备份旧证据，再移除 `--dry-run` 保存。保存会替换该股票的严格档案，不自动合并；缺失组仍为缺失，不自动补真值。文件结构为 `schema: livermore-evidence/v1`、`code`、`records`；组名为 `limits / auctions / index_auctions / regions`，完整字段、单位与时间约束由后台校验。导入不是来源认证。

## 未完成的交易边界

当前公开数据仍不足以放行严格利弗莫尔交易，所以不会凭来源参考制造买入。单股研究的真实历史回放仍保守阻止撮合。历史组合若未来补齐入场证据，仍是开盘估算成交，非交易所排队成交。

实时竞价数据校验要求不晚于9:25冻结、只接受9:30首30秒观察；现有盘中轮询不能补做早前竞价交易。真实盘中的 Z1 涨停顺延一次、跌停后的下一可交易开盘退出尚未实现完整状态机，所以本次**仍关闭利弗莫尔实时新增买入**，即使竞价数据合格也不能解除。旧利弗莫尔持仓仅更新估值并提示退出限制，不依据缺失的涨跌停价猜测可卖出。
