# 全球新闻：真实数据接入版

正式入口为本机3001端口工作台的“新闻页”。采用现有地球界面，但不再加载15条固定模拟新闻；独立设计预览仍保留合成数据，并明确标记。

## 新闻来源和时间

2026-11-16本机已实际验证以下公开入口可访问。本机首次接入保存59条7日以内资讯，不承诺涵盖全部全球新闻。媒体刊发速度、公开栏目容量和网络状况决定可见范围，不是交易所级实时快讯。

| 来源 | 范围和入口 |
| --- | --- |
| 新浪财经 · 全球市场 | [官方全球市场栏目](https://finance.sina.com.cn/roll/)，pageid=384、lid=2676的公开滚动接口；使用每条ctime，不把接口响应时间冒充新闻时间 |
| 中国新闻网 · 国际 | [官方RSS订阅入口](https://www.chinanews.com.cn/rss/)的world.xml；RSS提供的标题、链接、短摘要、发布时间 |
| 美联储 · 官方公告 | [官方RSS目录](https://www.federalreserve.gov/feeds/feeds.htm)的press_all.xml；属于宏观官方公告，不是综合世界新闻 |
| 欧洲央行 · 官方公告 | [官方RSS目录](https://www.ecb.europa.eu/home/html/rss.en.html)的press.html；属于宏观官方公告，不是综合世界新闻 |

只读取公开订阅/滚动入口，不抓文章全文、不打开付费内容、不绕过登录或访问限制。新闻文本按原文保留，界面用中文；外文没有默认机器翻译，不产生后台模型费用。原文链接在新窗口打开，注明来源。

北京时间用于页面显示；数据库保存有明确时区的UTC时间。没有有效发布时间、超过允许未来时差或已经超出7日窗口的条目不被标成最新新闻。

## 自动更新与旧缓存

后端运行期间每300秒检查一次来源；网页无需一直停留在新闻页。电脑关机、休眠或启动器关闭时不会继续抓取。重新启动后恢复检查，但不承诺补齐离线期间每一条新闻。

后端限制单轮并发3个请求、单源响应最多2MB、最多解析100项；同一时刻只允许一轮更新，手动刷新也受300秒全局冷却限制。支持ETag/Last-Modified条件请求与304，避免重复传输。401/403会停用该源，不绕过拒绝；需要确认来源权限后再由开发者处理。

源出错时保留最后成功数据并显示来源状态；不会偷偷换回模拟新闻。缓存过期会显示“旧缓存”或空列表，不能把缓存时间当成新闻发布时间。无法读写缓存则显示错误，不影响账号登录或其他研究功能。

## 地图和关联的边界

- 左侧新闻分页，每页40条；搜索覆盖7日缓存。地图只显示当前页，旋转地球不会过滤掉左侧列表。点击新闻可定位到有明确文本地名的示意点。
- 国家锚点是大致中心，不是事件精确位置。只在文本明确提及并能唯一识别时显示部分常见省市；多国、多地或无法识别时不编造坐标，不按媒体总部猜发生地。
- 新闻到板块：默认用有界中英关键词匹配，展示命中词和产业假设。验证模型API后，可以对当前新闻主动点击“AI分析关联板块”；已有同源快照的模型缓存自动复用。AI产业传导推测与原报道事实分开，不等于影响已被证实。
- 板块到股票：少量有公司官网/公告业务依据的候选，再与本机历史股票目录交集，排除30、688、92开头及名单内ST/退市名称。当前名称来自本机名单快照，不等于持续核验今日证券状态。
- 候选不等于“符合席位规则”或推荐买入。本版不编造财报、当日行情、竞价或筛选通过结果；无结果显示待核验，无关系不补入无关股票。
- 今日新闻不能进入11月12日历史预案。因此真实新闻的“进入研究”暂不启用；原合成新闻档案不受影响。后续接入新闻时点后的真实行情、财报及规则，才能建立可执行的时点一致研究。

## 缓存与配置

独立SQLite缓存默认`data/global-news.sqlite3`，与账号库、研究档案分开。保留最近7日且最多5000条，按日期索引分页读取。页面只保留当前40条与小型业务候选表，不将所有缓存塞入浏览器。关闭新闻页时销毁iframe及地图资源，隐藏页面暂停页面轮询，返回后检查缓存。

可选环境变量：

```text
CONTEST_NEWS_DB=  # 留空使用默认路径；自定义目录须先存在
CONTEST_NEWS_AI_DB=  # 留空使用项目根目录.news-ai.sqlite3；私人模型分析，不公开
CONTEST_NEWS_AUTO_REFRESH=1  # 0关闭后端定期检查；手动刷新仍受冷却与权限约束
```

新闻原文是第三方不可信内容，不能授予工具权限或变更席位规则。新闻抓取模块不读取模型Key、账号密码、持仓或个人研究记录，不向新闻源发送这些信息。

## AI分析的触发、证据与费用

主动点击一次，只请求当前会话已经验证的模型一次（JSON输出），发送该条新闻的标题、短摘要、来源、发布时间、原文链接与固定研究板块词表。不发送账号密码、个人研究记录、持仓或其他新闻；Key仅由后端用于既有模型服务的鉴权，不发送给新闻发布方。该模型服务可能计费，并按其自身数据政策处理输入。

新闻定时更新、搜索、翻页、切换席位、读取缓存都不会自动发起模型请求。无API配置时显示离线状态，不用关键词匹配冒充AI。HTTP错误、超时、格式或引文校验失败明确报错，不自动重试。离开/隐藏页面中止浏览器等待不保证已经提交的服务商请求被取消，可能仍产生费用；若后台成功，返回该新闻时可复用缓存。

AI返回最多8个固定词表内板块，每条含潜在方向、定性强弱、直接/间接关系、传导原因、输入原文的连续短引文及不确定性。不能核对原文的引文、未知板块ID、重复关系、未完整输出均不采用。模型可能判断错误；这是结构与引用一致性检查，不是对因果逻辑或市场影响的自动证实。没有足够关系可以返回空列表，不强行拼接。

红线表示AI推测的潜在产业利好，绿线表示潜在产业利空，明暗为定性影响等级，不是涨跌概率或已验证幅度。双向或不能判断的结果单独标注。不会让模型编造股票、财报、实时价格、席位通过结果或买卖订单；股票仍按已有可查业务目录展示并标为待核验。新增板块暂时没有经过核对的股票目录时，列表为空。

模型分析缓存按本机账号隔离，与公共新闻缓存、账号库及研究库分开；缓存Key包括新闻内容指纹、模型地址/名称和分析规则版本。新闻文本更新或切换模型后不复用旧结果。保留7日、全库最多2000条，每页至多读取40条；请求尝试在一小时后清理，每账号最多20次/小时、整站100次/小时、最多4个并发且同一账号最多1个。失败请求也计入尝试限制，避免持续点击产生费用；命中缓存不消耗请求次数。分析库不保存API Key，也不打包公开。
