版本：2026-11-17。目标约6分30秒，成片5—8分钟、至少1920×1080、普通话MP4，可加字幕。视频由本人录制；本稿不是成片，也不是已完成AI实测。

## 录制前

1. 启动http://127.0.0.1:3001/，使用自己的本机账号，无账号可注册。隐藏密码、Key输入，关闭个人通知，不展示.env、Cookie或私人数据库。
2. 确认真实历史档案可用。开发机3049只主板非ST、非退市股票；证据只到2026-11-12，历史模拟日2026-11-13。源码不附供应商档案，干净机须显式采集，不用合成股票替代。
3. 熟悉“启用自动模拟”、全市场扫描及自己的账本。已有完成轮次可直接展示已存结果，不删库或重置账户制造盈利。
4. 实际预跑一次基础席位AI单股研究或新闻主动关联，记下模型、时间、结果和错误。登录API验证不是当次研究成功，Mock和缓存不冒充新请求。
5. 新闻与历史研究分开录：当前新闻进入旧历史研究禁用，避免未来信息泄露；不沿用旧合成新闻镜头。
6. 数字、买入名单、新闻量和测试数以实际画面为准，不预设收益。没有成交、无已平仓样本或模型观望均可如实展示。

## 失败或无成交时

AI报错、超时、无额度或输出不合规时，保留错误，明确“这次真实AI未完成，下面仅演示已实现规则与数据流程”，将AI实测列待补。不用离线、后期配音或Mock假装成功。

新闻AI显示缓存时，说明是此前同新闻/模型的保存分析，不说是新调用。无关联、观望、持币或拒绝都是允许结果，不只剪盈利画面。

本轮零成交时，展示真实空账本、缺口与统计定义；可用本人此前保存且日期清楚的模拟订单，不制造订单，不导入私人账户或以合成样例冒充真实交易。

## 导出检查

- 5—8分钟、MP4、至少1080p、普通话清楚，完整试播检查小字与字幕。
- 含介绍、核心功能、AI亮点；明确真实历史、当前新闻、模型推断与虚拟资金的区别。
- 研究/复盘/审计职责不同，至少一个真实观望、未成交或资料不足分支。
- 无虚构AI成功、收益、平仓胜率、逐笔行情或严格核验状态。
- 无密码、Key、Cookie、个人信息、私人数据库或未授权资料。
- 不把本机地址称公网演示，最后按官网要求提交成片，脚本不能代替视频。
