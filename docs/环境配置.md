# 智慧交易助手环境配置

版本：2026-11-17。面向干净机复现。源码不带账号、研究、模拟账户、新闻/AI缓存、供应商行情或原始财报。采集工具随源码提供，须显式准备有权使用的数据。

## 安装、构建与启动

| 层级 | 文件或工具 | 用途 |
| --- | --- | --- |
| 后端/测试 | Python 3.10+、requirements.txt | FastAPI、httpx、Pydantic、python-dotenv、Uvicorn、pytest |
| 前端 | Node.js 20.9+、npm、web/package.json及package-lock.json | Next.js、React、TypeScript，按锁安装 |
| 可选文档 | requirements-authoring.txt | ReportLab、pypdf，网站无需 |

源码根目录执行：

~~~powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Push-Location web
npm.cmd ci
npm.cmd run build
Pop-Location
.\.venv\Scripts\python.exe launch.py --production
~~~

Node须在PATH，首次依赖安装需网络。构建按白名单准备新闻地图与协议资产，不读取私人数据库或Key；静态资产不代表已取得真实新闻，也不作为正式新闻失败后的合成回退。

入口http://127.0.0.1:3001/，后端127.0.0.1:8001。日常可双击“启动智慧交易助手.cmd”，优先项目.venv，有构建则用生产模式。调试可运行python launch.py（用项目解释器、不加--production）。

保持启动器运行。Ctrl+C、关闭启动器、子进程退出或电脑重启后需重启；只打开网页不会启动服务。这不是开机自启服务，环回地址不是公网部署。

## 账号和“离线”

登录页提供注册。账号2—32个允许字符，密码10—128字符并确认一致，服务端检查重复与频率。账号仅属本机，注册后仍须选离线或验证模型。旧账号继续原密码，同名注册不重置；短信、手机号绑定已移除，无密码找回。

离线模式表示不调用付费语言模型，不等于全站断网：默认全球新闻后台联网，实时模拟、手动刷新和采集也会联网。已有本地历史与规则无需模型Key、不产生模型调用费；网络及第三方数据许可另按实际条件。

尽量纯本地时设CONTEST_NEWS_AUTO_REFRESH=0后重启，不点实时、新闻刷新、采集或AI。关闭后台新闻不关闭手动联网入口。源码无行情时保留空状态，不退回测试fixture冒充股票。

## 干净机准备历史数据

开发机已校验3049只主板非ST、非退市股票，未复权、成交量单位股。历史范围2024-11-01至2026-11-13，决策固定2026-11-12，后续模拟固定2026-11-13。名单是下载时快照，非历史成分或历史ST状态重建。

源码ZIP不含供应商档案。确认有权使用公开源后显式执行：

~~~powershell
.\.venv\Scripts\python.exe tools/download_market_history.py --source sina
~~~

默认写data/market-history/2026-11-13/。检查manifest.json、失败项和网页状态；干净机数量以实际成功校验结果为准，不硬填3049。该下载命令使用固定默认输出目录，CONTEST_MARKET_DATA_DIR不是其输出参数。

利弗莫尔参考和覆盖工具：

~~~powershell
.\.venv\Scripts\python.exe tools/download_livermore_data.py --dry-run
.\.venv\Scripts\python.exe tools/download_livermore_data.py
.\.venv\Scripts\python.exe tools/download_livermore_data.py --refresh-coverage
~~~

依次为只读名单（零网络零写入）、显式采集两个日期的公共涨停参考、仅本地重建覆盖。参考不等于精确涨停价或竞价；严格限价/状态、9:25股票/指数竞价、区域确认不足时不交易，当前实时新增买单禁用。

已有合规授权本地证据时，可先运行tools/import_livermore_evidence.py --input 本机文件.json --code 股票代码 --dry-run，再决定正式导入。格式以原模块为准，不照抄测试假来源或手填“已核验”。正式导入替换该单股证据档案，先保留合法原档备份。

巴菲特公共财务参考、原始披露数值核对、严格历史时点核验是不同步骤；工具与说明见README及财务资料文档。连续年度、版本、维持性资本开支、股本或人工生意证据不足时保留缺口和现金，不把公共参考等同可交易。

外部拒绝、限流、跳转或不可用时按工具错误停止，不换域、代理、提取凭据或绕过。原始数据是否可再分发须单独确认，不加入公开仓库。

## 完整环境模板

按需仅在.env不存在时复制.env.example为本机.env，不覆盖已有配置。后端加载根.env不覆盖已有进程环境；修改后重启。Node构建和独立工具不保证自动读取后端.env，应核对进程环境。不要在聊天、终端回显或录屏展示真实值。

### 模型变量

| 变量 | 默认/空值 | 说明 |
| --- | --- | --- |
| CONTEST_LLM_BASE_URL | 空时无服务器预设 | Chat Completions基础地址，不加/chat/completions；远程HTTPS，管理端预设允许环回HTTP |
| CONTEST_LLM_MODEL | 空时无服务器预设 | 提供商真实模型标识，不能靠名称推定权限、额度、工具兼容 |
| CONTEST_LLM_API_KEY | 空时无服务器预设 | 仅后端，不放NEXT_PUBLIC_*、浏览器持久存储、仓库或录屏 |
| CONTEST_LLM_MAX_RUNS | 20，范围1—200 | 每后端进程AI预案尝试预算，失败计入；不是费用上限，不替代新闻AI独立频控 |

网页也可配置受支持模型。配置验证会请求模型、可能计费；基础研究与新闻关联仍须主动触发，验证通过不等于实际研究成功。基础研究工具协议与新闻结构化关联是两条流程，另外两席位是确定性规则而非付费模型执行器。

### 目录与私有存储

| 变量 | 空值默认 | 数据性质 |
| --- | --- | --- |
| CONTEST_ACCOUNT_DB | .workspace-account.sqlite3 | 本机账号、加盐哈希，不分发 |
| CONTEST_RESEARCH_DB | .research-records.sqlite3 | 按账号隔离研究档案，不分发 |
| CONTEST_PAPER_DB | .paper-accounts.sqlite3 | 虚拟账户、订单、决策与快照，不分发 |
| CONTEST_MARKET_DATA_DIR | data/market-history/2026-11-13/ | 历史档案目录，不是SQLite文件；供应商档案不公开 |
| CONTEST_NEWS_DB | data/global-news.sqlite3 | 独立真实新闻缓存，不分发 |
| CONTEST_NEWS_AI_DB | .news-ai.sqlite3 | 按账号隔离AI标注，不分发 |
| CONTEST_NEWS_AUTO_REFRESH | 1 | 默认运行时每300秒检查允许源；0关闭后台刷新，不关闭手动请求 |

默认位置在项目根下。自定义路径建议绝对路径，提前准备可写父目录，测试不要指向私人库。独立工具若只读进程环境，可在运行它的PowerShell显式设置目录，不能假定自动加载.env。

新闻有界缓存，来源状态、时间和条数以实际为准，不承诺全部全球新闻。AI仅依据标题和短摘要，缓存命中不等于新请求。

登录会话和手动模型配置在当前后端内存，会话有效8小时；单股活动预案另有1小时/至多100条限制。持久研究和模拟账户不同于活动预案。重启可重新登录读已存记录，不自动补算未存后续；不删库排错或通过同名注册找回密码。

### 构建进程变量

| 变量 | 默认 | 注意 |
| --- | --- | --- |
| CONTEST_PYTHON | 新闻构建器优先.venv，否则python | 在运行npm的shell设置解释器；Node不自动读后端.env |
| CONTEST_WEB_BUILD_DIR | .next | 仅.next-seat启用备用，构建/启动一致；一般不设，CMD启动器会清除 |

默认端口由启动器和Next配置固定，无额外端口变量。公网HTTPS、隔离、并发与成本需另行部署，本机启动不等于安全公网方案。

## 测试与排错

~~~powershell
.\.venv\Scripts\python.exe -m pytest tests -q
Push-Location web
npm.cmd test
npm.cmd run lint
Pop-Location
~~~

测试隔离fixture，不请求真实模型，不证明供应商可用性、许可、排队成交或策略盈利。按本次真实输出记录，不沿用旧测试数。

| 现象 | 处理方向 |
| --- | --- |
| ERR_CONNECTION_REFUSED | 启动器是否运行，3001/8001是否由本项目监听，先启动再刷新 |
| 干净机无股票 | 原始数据不随源码是预期；显式采集校验，不转合成交易 |
| 决策日未变今日 | 固定11-12决策/11-13模拟，不是自动更新到今日回测 |
| 新闻空或部分源失败 | 检查真实源状态和更新时间，不编造、不绕过 |
| 当前新闻不能进入历史 | 防未来信息倒灌，不靠换按钮解除 |
| AI错误或超时 | 核对模型、权限、额度、协议；不假装离线结果是真实成功 |
| 席位没买入 | 查严格限价/竞价或财务/生意缺口，参考覆盖不等于通过 |
| 无胜率或回撤不足 | 仅按已存平仓和日快照统计，不用浮盈或其他日期补 |
| 重启要求登录 | 内存会话失效正常，原账号登录，不覆盖密码、不删库 |
