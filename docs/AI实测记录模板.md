# 智慧交易助手 AI 实测记录模板

此表只记录实际完成的外部模型调用，不是已完成实测证明。未操作时保留未实测，不把 Mock 协议测试、离线规则、合成回放或历史截图填成真实模型成功。不要记录 Key、Authorization 头、Cookie、密码和私人持仓。

## 配置验证与预案实测分开

API 设置验证用合成证据探测工具和结构化输出，只证明那次配置探测结果，不代表研究草稿已生成预案，也不保证所有案例成功。视频称“本段是真实模型调用”时，应有对应的逐次预案实测记录。

| 字段 | 当次真实记录 |
| --- | --- |
| 操作日期与时间 | 未实测；完成后填北京时间和明确日期 |
| 操作者或内部编号 | 待填写，不含证件信息 |
| 源码版本 | 实际提交或发布版本；无 Git 时如实填源码快照与校验摘要 |
| 服务商与模型标识 | 实际填写，不凭宣传名推断 |
| 基础接口地址 | 可公开的主机和路径，不含 Key、用户名或私有 URL 参数 |
| 操作类型 | 配置探测 / 基础席位真实历史研究 / 主动新闻板块分析，择一 |
| 案例和研究记录标识 | 真实股票代码及固定决策日，或新闻ID/来源/发布时间；合成证据仅在配置探测/显式测试时标明 |
| 实际生成方式 | 当次屏幕显示的真实 AI 分析，不能填离线 |
| 工具结果 | 基础研究检查唯一 get_history_evidence 和中性案例；新闻检查允许板块、引用与结构，不假装同一工具流程 |
| 证据时点 | 实际决策日，是否仅使用截止前证据，不补未来价格 |
| 输出 | 基础研究 simulate/hold；新闻关联/无关联/不确定；解析或服务失败按实际填写 |
| 独立风控 | 通过或拦截，以及可读原因 |
| 费用 | 本人核实账单后填写；不清楚则写未知 |
| 耗时 | 有可靠计时才填并说明口径，否则写未测 |
| 脱敏证据 | 实际截图、录屏时段或非敏感轨迹相对路径 |
| 失败与不确定性 | 如实保留失败、观望、超时、限额，不删除不利结果 |

多次运行每次另表编号，不把几次结果合成一个成功率。统计成功率需事先定义样本、分母和通过标准，少量合成案例不能支持真实投资表现推断。

## 最小验收步骤

1. 使用本人有权访问的兼容模型主动验证配置，只保存脱敏结果。
2. 基础席位选择本地真实历史股票并切到AI分析，或在新闻页主动分析一条真实新闻；保留实际模式、决策日/新闻时间、引用、响应与独立校验。配置探测使用的合成证据不能冒充正式研究。
3. 观望、拦截、服务失败均照实记录。展示固定撮合分支时另用离线规则，两种模式分别说明。
4. 从研究记录重新打开已存档案，对照是否一致，不直接修改 SQLite 或用后来结果替换当时预案。
5. 检查公开材料中无密钥、请求头、密码、Cookie、手机号和未授权个人数据。
