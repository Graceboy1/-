## 范围与来源

- 目标日期：2026-11-13（周五）；请求历史范围：2024-11-01至2026-11-13。新上市、停牌或源缺失的股票可能不足两年。
- 名单来源：下载时新浪财经A股名单快照；保留000、001、002、003、600、601、603、605开头且当前名称不含ST、退的股票，排除创业板、科创板、北交所。
- 这是当前名单筛选，不是历史成分重建；不能证明周五的ST状态，也不能用于声称无幸存者偏差的全市场回测。
- 历史日线来源：腾讯证券、新浪财经。逐只保存来源、下载时间、SHA-256；不复权。成交量统一为股：腾讯原始手数乘100，新浪原始股数保留。
- 未取得的成交额、换手率保留空值；本日线档案本身不含财报、分钟线、逐笔、五档、历史精确涨跌停价或停复牌日历。少量单独补充的真实年度财务资料见[三席位真实数据接入](三席位真实数据接入.md)，不能把当前检索版本当成已核对的原始历史版本。
- 清单的下载成功、失败、待处理和周五有效记录数分开统计。没有周五记录不等于已证实停牌，不补造日线。

## 打开和使用

1. 运行项目、登录或注册，选择离线模式即可，不必为看行情配置模型。
2. 进入“研究台”，存在可读档案时默认载入目录中的首只真实历史股票，下方“决策日行情”同步显示截至11月12日的证据。不会自动调用模型、生成预案或买入。
3. 在“2026年11月13日 · 本地行情档案”搜索代码或名称，点击股票即同步下方真实基础席位研究；查看截至11月12日最近120根历史日线，图表默认展示最近45根。
4. 切换三个席位时保留同一真实股票，读取该席位的真实指标或明确缺口；点击“生成并冻结预案”才创建独立研究，不覆盖已有冻结档案。默认离线规则，基础席位自行选择已验证AI后才可能调用、计费。正式页不再提供新建合成情景演示。
5. “仅揭示周五行情”只观察11月13日价格，不是模拟订单、席位收益或预测成功率。

三个席位均使用真实行情，但不能用价格替代财报、精确涨停和竞价。利弗莫尔展示真实120日区间与待核验项；巴菲特区分真实财务参考与严格时点证据。证据不足的席位保持观望，观望可主动揭示后续真实价格；条件预案缺执行证据时风控阻断成交。不能根据周五当日涨幅假设当天买入可兑现收益，A股仍受T+1等实际约束。

## 为什么决策日不是档案最后一天、买了什么在哪里看

档案行情截至11月13日；本轮决策证据截止11月12日；11月13日是后续观察日。旧合成研究记录的10月23日不被改写，可从已有档案只读查看。正式新演示使用真实股票，这里不是实时行情，也没有每日自动交易任务。

主区按页面区分职责：研究台启用全市场模拟并显示独立账户、订单与持仓，复盘台显示账本收益统计及订单日K播放，审计台显示累计判断和未成交原因。是否买入由本人的已存订单决定，不预设“已买”或“一定没有交易”。

折叠单股研究工具另行显示所选股票、冻结预案和单股回放状态。其严格真实历史撮合仍受限，条件预案不能当作已买入；独立单股研究资金不混入主区的三个累计模拟账户。旧合成档案仅兼容查看及测试，不挪用其收益。主区和单股工具均不会因切换页面补单或改写旧记录。

## 本机存储和内存

`data/market-history/2026-11-13/`内包含manifest.json、universe.json、index.sqlite3和daily目录。日线按股票gzip压缩保存；页面每次读取20个目录项，图表按单只股票读取，传给研究与模型最多120根，不把整个市场塞入浏览器或常驻内存。

本地数据目录已被Git忽略并排除在公开源码打包白名单外。使用公开接口不等于取得再分发或商用授权；参赛录屏如实标注来源，公开分发原始数据前自行确认数据许可。

## 重新下载或补齐

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -X utf8 tools/download_market_history.py --source sina
```

默认断点续传，只请求未成功股票，单源节流并限制并发。授权拒绝或访问拦截会停止该源，不绕过限制；其他临时失败会有限重试并记入清单。下载期间页面可手动刷新状态。

可用环境变量`CONTEST_MARKET_DATA_DIR`指定同格式归档目录。依赖和日期常量见下载脚本；本功能是固定日期历史样本，不是实时行情服务，也不是每日自动更新任务。

旧版已封存的ZIP、PDF不会自动同步本功能；如更新参赛材料，请重新审核测试、文档与数据许可后另存新版本。
