多席位策略研究与交易复盘。项目把决策时点的证据、条件预案、服务器独立风控与事后回放分开，供使用者检查一次模拟决策如何形成、是否符合约束，以及后续为什么成交、未成交或延后退出。

## 核心功能与边界

- **自主模拟交易**：工作台主区是三个独立的10万元虚拟账户。一次启用后自动扫描本地全市场、按注册规则形成判断，并记录模拟买卖、持仓、费用与盈亏，不再逐股点击生成。历史演示与实时账本分开；单股研究收进折叠工具。见[自主模拟交易](docs/自主模拟交易.md)。
- **复盘台增强**：每笔已保存模拟订单可进入真实日K回放，支持播放、暂停、逐根前后步进、进度和速度控制；买卖点只随已揭示日K出现。完整账本收益统计提供已平仓胜负、胜率、盈亏因子、费用、浮盈亏、收益曲线及日快照回撤，不把单日样本年化或冒称完整盘中回撤。数据仍是日K，不是分钟线/逐笔行情。
- **历史股票行情**：三个席位共用已下载的真实股票代码、名称与日线，切换席位保留同一股票、分别分析，不回退合成情景。目录分页、单股读取；没有档案时明确要求导入，不展示虚构股票。档案目标日2026-11-13，决策证据截至11-12；后续行情须主动揭示。缺执行证据时不模拟成交和收益。见[历史行情使用说明](docs/历史行情使用说明.md)。
- **研究台**：基础、利弗莫尔和巴菲特三个席位使用相互独立的证据、条件与回放纪律。先生成预案或观望，再由后端校验并冻结。
- **真实席位资料**：利弗莫尔计算真实120日价格区间，精确涨停和竞价未知时观望；巴菲特读取真实财务资料核对，未核原始历史版本的报表与时点合格证据隔离，不伪造维持性开支、股数或人工护城河/能力圈认可。正式目录提供已有财务资料股票快捷入口；这些不是推荐或规则通过名单。见[三席位真实数据接入](docs/三席位真实数据接入.md)。
- **巴菲特数据补齐**：支持现有主板目录的三年四表批量参考下载、原始年报归档和逐项缺口清单；原始版本、股数、维持性资本开支及人工确认未齐时不交易。见[数据补齐说明](docs/巴菲特数据补齐说明.md)。
- **巴菲特判断接入**：离线核对原年报数值、单位、PDF页码与指纹，核对后的事实进入全市场席位判断，主区展示接入状态；利润、ROE、负债等项目独立判断，完整历史版本及业务确认缺失时仍禁止估值放行和买入。见[接入验收](docs/巴菲特数据接入验收.md)。
- **利弗莫尔数据接入**：全市场120日位置、同日涨停池来源参考、精确限价与历史证券状态、真实9:25竞价和区域确认分层读取；参考不冒充已核验。研究/审计主区可查看覆盖及缺项，独立入场门控不能用全天量代替竞价。当前仍缺严格执行资料，实时完整退出纪律尚未启用。见[接入验收](docs/利弗莫尔数据接入验收.md)。
- **真实 AI**：基础席位支持已配置模型的工具调用和 JSON 预案，新闻页另支持主动单条板块分析；利弗莫尔、巴菲特交易预案为思想启发的确定性规则，不是名人模型或蒸馏模型。失败会显示错误，不静默伪装为离线成功。
- **复盘台与审计台**：操作者主动揭示后续，只按冻结预案回放，记录 T+1、封板不成交、停牌、跌停受阻、独立风控与调用轨迹。三台显示同一研究对象、预案/模拟买入/持仓状态；合成成交明细可查日期、方向、价量金额，不把真实价格研究伪装成交易。哈希识别冻结内容，不等于第三方可信存证。
- **全球新闻**：正式工作台接入真实全球财经、国际新闻和宏观官方公告，运行期间每5分钟检查更新。当前页40条、7日缓存、最多5000条；来源、时间、失败和旧缓存明确标注。主动点击可用已验证API分析当前新闻关联板块，展示传导原因、原文引文及不确定性，按账号缓存复用，不自动批量计费；无AI结果时仍明确标识关键词候选。关联股票仍待核验，不假装通过席位或影响验证。见[全球新闻使用说明](docs/全球新闻使用说明.md)。
- **新闻进入研究**：原合成预览仍按合成案例重新核对映射并创建独立草稿。正式实时新闻暂不启用“进入研究”，避免把今日新闻塞进11月12日的历史决策；不覆盖旧冻结记录，不自动调用模型。
- **研究记录**：SQLite 持久保存新闻、规则源码指纹、时点证据、预案、校验与已执行回放。按创建日期和席位筛选，每页 10 条；详情按需读取。

自主模拟按每席位独立组合累计虚拟资金，账本采用明确假设的历史开盘或下一条有效实时报价估算撮合，不能证明真实成交。历史当天买入只收盘估值，T+1不能当天卖出。折叠的单股研究记录仍各自独立，不混入组合收益；它的严格执行门槛与纸面估算模型不同。旧合成档案不能冒充本次真实数据演示收益。

## 技术架构

```text
浏览器 Next.js / React 工作台与同源新闻地球
      |
      | /contest-api 同源接口
      v
FastAPI
  登录会话、截止前证据、工具权限
  基础席位 AI / 三席位本地规则
  独立风控、冻结预案、主动回放
      |
      v
SQLite 研究档案（与本机账号库分开）
```

模型不能直接运行回放、决定成交或解除风控。预案阶段只给模型当前决策日及以前的证据，真实历史与合成案例明确区分；新闻关联仅作可追溯研究背景，不替代席位买卖规则。

## 干净环境安装和运行

在 Windows PowerShell 的项目根目录执行。建议 Python 3.10+、Node.js 20.9+ 与 npm，Node.js 和 npm 应在 PATH 中。不要复制开发机器的依赖、缓存或数据库。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Push-Location web
npm.cmd ci
npm.cmd run build
Pop-Location
.\.venv\Scripts\python.exe launch.py --production
```

入口 <http://127.0.0.1:3001/>，API 使用 `127.0.0.1:8001`。登录页始终提供“登录 / 注册账号”切换，没有默认账号或密码。新使用者先注册，再选离线模式或验证自己的模型 API。离线模式不调用模型、不需要 Key；正式股票研究仍需合法准备真实历史档案，公开源码不附第三方原始行情及私人数据库，缺数据时不会回退成合成交易。见[历史行情使用说明](docs/历史行情使用说明.md)。全球新闻默认可能联网更新；完全断网时只能查看已存在的本地缓存，或显示不可用。

安装和构建完成后，可双击 `启动智慧交易助手.cmd`。它兼容原启动入口，优先项目 `.venv`，有 `.next` 构建时选择生产模式。日常启动无需重复安装或构建；开发时可运行 `.\.venv\Scripts\python.exe launch.py`。

**没有开机自启或系统服务托管。** 保持启动程序运行；Ctrl+C、关闭启动器或电脑重启后，服务可能停止。遇到 `ERR_CONNECTION_REFUSED`，先重新启动项目，看到启动成功再刷新。只打开网址不能自动启动服务，localhost 也不是公网地址。完整步骤见 [环境配置](docs/环境配置.md)。

## 注册与登录

登录页可直接切换到“注册账号”，填写账号、密码和确认密码。账号为 2-32 个允许的字符，注册密码为 10-128 个字符，两次密码必须一致。注册成功后进入模型配置或离线模式选择，不会自动请求模型。账号已存在时应直接登录或换用另一个新账号名；注册不是重置密码，不能覆盖已有账号。

本版支持同一台电脑注册多个独立账号。升级时保留旧账号用户名与原加盐密码哈希，旧账号仍使用原密码登录，原研究记录按原用户名归属继续可读。新账号只能读取自己的研究档案；登录、模型配置与活动回放仍按会话隔离。

短信登录和手机号绑定入口已移除。当前没有密码重置或账号找回功能，请自行妥善保管账号密码，不要把账号数据库作为公开材料分发。本机注册功能不等于具备公网多用户生产部署能力。

## AI 模式和配置

交易预案仅基础席位可选 AI 分析。服务端要求模型唯一调用 `get_history_evidence`，核对当前中性案例 ID，再返回截止前证据并要求 JSON 预案。后端独立校验，不把模型文字当作执行指令。一次预案通常涉及两次模型请求，可能计费。新闻页另有独立的单条新闻AI板块分析，主动点击才请求一次，不受所选交易席位限制，也不生成订单。

配置方式二选一：

1. 登录后在 API 设置填写受支持 HTTPS 基础地址、模型名和自己的 Key，再主动验证。
2. 用 [.env.example](.env.example) 配置后端进程环境变量或本机 `.env`，重启后在设置页验证服务器预设。

网页地址白名单在 `server/model_setup.py`，管理员自建服务通过服务器预设接入。基础地址不要附加 `/chat/completions`。模型名不能替代工具能力实测。

配置验证只说明那次探测结果，**不代表每轮研究预案都已实测成功**。按 [AI 实测记录模板](docs/AI实测记录模板.md)逐次记录真实操作。Mock 协议测试、离线规则与合成回放不能代替真实服务调用证明。失败、超时和观望均应如实保留。

## 数据 会话与安全

| 类型 | 保存方式 |
| --- | --- |
| 本机账号 | 默认 `.workspace-account.sqlite3`，保存各账号的加盐密码哈希，兼容保留旧账号，不分发 |
| 登录及手动模型配置 | 当前后端内存；会话 8 小时，退出或重启后重新登录并验证 |
| 活动回放预案 | 进程内至多 100 条，单条一小时，绑定当前会话 |
| 已存研究与回放档案 | 默认 `.research-records.sqlite3` 持久保存，按账号隔离并分页读取 |
| 自主模拟组合 | 默认 `.paper-accounts.sqlite3` 持久保存账户、完整订单、持仓、日快照及有界决策样本；账号、历史/实时模式和席位隔离 |
| 私人新闻AI分析 | 默认 `.news-ai.sqlite3` 按账号隔离，7日且全库最多2000条，不含Key |

活动预案过期或服务重启后，已存档案仍可只读查看，不自动补算尚未保存的后续行情。继续分析应“以当前情景新建研究”。升级前已丢失的纯内存预案无法追溯恢复。

- 不公开 `.env`、有效 Key、账号库、研究库、日志、手机号、持仓或未授权源包。不要用 `NEXT_PUBLIC_*` 保存密钥，不将密钥放前端、浏览器存储、录屏或截图。
- 手动模型 Key 不写入研究档案；服务器预设由本人保管于环境变量或本机 `.env`。
- 当前认证、Cookie、Host 限制专为环回 HTTP 设计，不能直接开放公网。可选公网体验需要另行处理 HTTPS、认证、隔离、并发和模型费用。
- 注册与登录仅使用账号密码，不再提供短信或手机号绑定流程；不提供密码重置。
